1. Настройки прав пользователей

Для обеспечения безопасности в Системе предусмотрены группы доступа для пользователей, позволяющие разделить вывод и изменение хранимых данных в базе для конкретных сотрудников.

Для предоставления прав пользователям необходимо перейти в подсистему «Администрирование» в раздел «Настройки пользователей и прав», затем необходимо выбрать раздел «Пользователи» и в открытом окне выбрать необходимого пользователя двойным нажатием левой кнопкой мыши, в карточке пользователя требуется нажать на гиперссылку «Права доступа» и установить флажки напротив необходимых профилей групп доступа, после окончания заполнения прав необходимо нажать кнопку «Записать».

3. Настройки расчета заработной платы

Для корректного отражения расчетов с сотрудниками требуется заполнить значение текущей ставки НДФЛ, заполнить рабочий график и указать условия оплаты для каждого сотрудника.

Отражение ставки НДФЛ выполняется в разделе «Ставки НДФЛ» подсистемы «Расчет зарплаты»:

В открывшейся форме ставок НДФЛ необходимо нажать кнопку «Создать», выбрать период, с которого ставка будет действовать и размер в процентах, затем нужно нажать кнопку «Записать и закрыть».

Заполнение рабочего графика выполняется с помощью обработки «Заполнение графика», расположенного в разделе «Сервис» подсистемы «Расчет зарплаты»:

При переходе откроется форма, в которой выбирается сотрудник, период, на который устанавливается график работы, а также выходные дни (например, если выходные суббота и воскресенье, то указывается «6, 7»), затем требуется нажать на кнопку «Заполнить».

Расчет заработной платы выполняется на основании условий оплаты сотрудников, заполняющихся в разделе «Условия оплаты сотрудников» подсистемы «Расчет зарплаты».
